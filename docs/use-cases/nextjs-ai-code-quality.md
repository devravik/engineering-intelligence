# Next.js Code Quality: AI-Generated App Router & Server Action Review

Engineering Intelligence provides deterministic quality control for Next.js applications built with AI coding agents. It detects authorization gaps in Server Actions, N+1 queries in React Server Components, table-locking migrations, and AI UI slop in Tailwind-based component hierarchies.

Next.js's App Router and Server Actions have specific patterns that AI agents consistently mishandle. Because Server Actions execute on the server with direct database access, a missing authorization guard is a direct data breach risk. Engineering Intelligence understands Next.js conventions and applies targeted rules.

---

## What It Catches in Next.js AI-Generated Code

### Server Actions Without Authorization (`API-001`)
AI agents generate Server Actions that handle form submissions and mutations without verifying the caller owns the resource:

```typescript
// What the agent writes:
'use server'
export async function deleteProject(projectId: string) {
  await db.project.delete({ where: { id: projectId } });
}
// Missing: auth().userId ownership check — any authenticated user can delete any project
```

Engineering Intelligence flags mutating Server Actions lacking ownership or role verification.

### N+1 Queries in React Server Components (`DB-002`)
When rendering lists via React Server Components, agents fetch parent entities and individually query children per-item:

```typescript
// What the agent writes:
export async function ProjectList() {
  const projects = await db.project.findMany();
  return projects.map(async (p) => {
    const owner = await db.user.findUnique({ where: { id: p.ownerId } }); // N+1
    return <ProjectCard project={p} owner={owner} />;
  });
}
```

### Route Handler Security Gaps (`SEC-001`, `API-001`)
`/api/` route handlers generated by agents frequently omit session validation, rate limiting, and input sanitization.

### Destructive Prisma Migrations (`DB-003`)
Agents add `NOT NULL` columns to tables with existing rows without providing defaults, generating table-locking Prisma migrations that will fail or cause downtime on production Postgres.

### AI UI Slop in App Components (`UI-COLOR-001`, `UI-SPATIAL-001`, `UI-SLOP-003`)
Next.js components generated by agents use generic Tailwind patterns:
- `bg-gradient-to-r from-purple-600 to-indigo-600` hero sections
- Everything wrapped in `<Card>` components with `shadow-lg rounded-xl`
- Body copy universally `text-center`

## CI Gate for Next.js Projects

```yaml
# .github/workflows/quality-gate.yml
name: Engineering Quality Gate
on:
  pull_request:
    paths:
      - 'src/app/**'
      - 'prisma/**'
      - 'src/components/**'
jobs:
  quality-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - run: npx --yes @devravik/engineering-intelligence detect --changed
      - run: npx --yes @devravik/engineering-intelligence ship
```
